# OSRS_MEGARARE_PROJECT
Information Science Project on Old School Runescape Items  
by Simon Spillane

***Goal:***
Data analysis project looking at the historical price and volume of OLD School Runescape (OSRS) Megarares using data from OSRS Wiki API. The goal is to to compare historical market trends to game updates to discover correlations between price/volume fluctuations with item data.
